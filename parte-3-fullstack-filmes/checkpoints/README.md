# Checkpoints do projeto Filmes

Estados intermediários do projeto, para você conferir o seu código ao final de uma etapa.
Cada pasta roda sozinha (`npm install` + `npm run dev` no frontend; `pip install -r requirements.txt` + `python main.py` no backend).

| Pasta | Corresponde ao final da aula | O que já funciona |
| --- | --- | --- |
| `aula-23-header-e-gerenciamento` | 23 | Formulário (só mostra o objeto no console), Header, rotas e lista de filmes **de mentira** |
| `aula-27-consumindo-api` | 27 | Frontend ligado à API: lista os filmes do banco e cadastra pelo formulário. Botões Editar/Excluir ainda só escrevem no console |

O projeto completo (aulas 28 a 30, com edição, exclusão, detalhes, pesquisa, validação e testes) está em `../projeto-filmes`.
